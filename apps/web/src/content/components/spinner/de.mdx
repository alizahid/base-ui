# Spinner

## Beispiele

### Größe

<Example>
  <Spinner size="1" />

### Mit Kindelementen

<Example>
  <Spinner loading><Switch defaultChecked /></Spinner>
  <Spinner loading={false}><Switch defaultChecked /></Spinner>
</Example>

<Example>
  <Button disabled><Spinner loading>Merken</Spinner></Button>
  <Button><Spinner loading={false}>Merken</Spinner></Button>
</Example>
