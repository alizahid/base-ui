<Example>
  <NumberField aria-label="الكمية" className="w-32" defaultValue={1} size="1" />
  <NumberField aria-label="الكمية" className="w-32" defaultValue={1} size="2" />

<Example>
  <NumberField aria-label="الكمية" className="w-32" defaultValue={1} variant="surface" />

</Example>

<Example>
  <NumberField aria-label="الكمية" className="w-32" defaultValue={1} color="indigo" variant="soft" />

### الحد الأدنى والأقصى والخطوة

<Example>
  <NumberField aria-label="الكمية" className="w-32" defaultValue={5} max={10} min={0} step={5} />
</Example>

### التنسيق

<Example>
